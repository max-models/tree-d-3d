## What is included

<CardGrid>
	<Card title="Flat quadtree" icon="open-book">
		Point charges (3D Coulomb) or line charges (2D Poisson) at any targets, by Barnes-Hut tree walk or direct sum.
	</Card>
	<Card title="Fast multipole method" icon="rocket">
		O(N) fields of line charges with a dual-tree traversal and complex multipole expansions.
	</Card>
	<Card title="Simulation" icon="document">
		Second-order time integration with a uniform magnetic field, absorbing walls and cached fields.
	</Card>
	<Card title="Kernels" icon="setting">
		Every kernel in Pyccel, NumPy, CUDA and Metal, with the same arguments.
	</Card>
</CardGrid>
